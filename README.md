# SkillSwap

A peer-to-peer skill exchange platform that enables users to teach and learn skills from one another through a collaborative community-driven system.

## Features

* User Registration and Management
* User Profiles
* Skill Listings
* Skill Search and Discovery
* Skill Exchange Requests
* RESTful API Architecture
* Layered Spring Boot Backend

## Tech Stack

* Java
* Spring Boot
* Maven
* Spring Data JPA
* MySQL
* REST APIs

## Project Structure
